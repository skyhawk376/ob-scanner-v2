# Frontend — Scanner OB 5 étoiles

React + Vite + Tailwind + TypeScript + TradingView lightweight-charts.

```bash
# API must be on :8000 (Vite proxies /api)
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # dist/
```

Env: `VITE_API_URL` (optional; default `/api` via Vite proxy).
